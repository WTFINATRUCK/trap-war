# Admin bot avatars (human look)

| File | Persona | Role |
|------|---------|------|
| `stacks.jpg` | **Stacks** | Play / game bot |
| `kayla.jpg` | **Kayla** | Community host |
| `bigl.jpg` | **Big Lou** | Guard / security |

Apply to Telegram:

```bash
npm run bot:personas
```

Or BotFather → `/setuserpic` → pick bot → send the JPG.

Swap any file (square ~512–1024px works best), then re-run `bot:personas`.
