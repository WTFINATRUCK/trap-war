# Trap War

**Gamified Liquidity Provision & DeFi Onboarding for Normies**

Trap War is a Dope Wars-style 30-day city-to-city hustle game where players learn real DeFi by providing liquidity. Assets represent LP positions. Police raids = impermanent loss. Dynamic evolving PFP NFTs show yield and progression in real time.

## Current Status
- Working local script prototype (dark cyber-street UI with cyan accents)
- Protected gas/stash reserves (auto-locks % of wins)
- Pay-to-Earn mechanics + SIM boost
- Founder 1-of-1 PFP NFT system
- Rich dynamic NFT evolution system designed
- Referral engine ("Everybody Eats")
- Weapons & transportation as LP positions
- Random robbery events with ecosystem TVL cut
- Planned: Base + Aerodrome real LP integration

## Goal
Scale to millions in TVL in 30-90 days while onboarding normies into real DeFi on Base.

## Tech Direction
- Primary chain: Base (Aerodrome for LP)
- Dynamic PFP NFTs (generative, evolving, yield-visible)
- Strong referral + crew economy
